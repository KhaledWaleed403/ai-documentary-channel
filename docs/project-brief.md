# Project Brief

## Concept
An explainer channel that makes invisible processes visible: how signals travel, how machines work inside, how systems pass energy, data or matter from one stage to the next. Each video turns one "how does that actually work?" question into a clear, animated mental model.

## Audience
- Curious adults and students (roughly 16+) who want real understanding, not trivia.
- Comfortable with some technical vocabulary when it is introduced plainly.
- Watching on desktop and phone; every frame must read at small sizes.

## Formats
| Format | Length | Aspect | Purpose |
| --- | --- | --- | --- |
| Long explainer | 8–15 min | 16:9 (1920×1080) | Full mental model of one system |
| Short | 30–60 s | 9:16 (1080×1920) | One idea, one "aha", links to the long video |

## Content goals
- Each episode answers one specific question and ends with a model the viewer can reuse.
- Build understanding step by step: whole system → parts → flow through the parts → why it matters.
- Accuracy first: every factual claim is sourced and checked before animation begins.
- Build a reusable visual toolkit so production speeds up over time.

## Production principles
1. **Show the mechanism.** Prefer an animated process over a talking point.
2. **One idea per beat.** Each scene changes one thing on screen.
3. **Honest simplification.** Simplify, but flag when a model is simplified; never invent mechanisms.
4. **Consistent but not identical.** Shared primitives and grammar; each episode gets its own palette accent, framing and pacing.
5. **Narration leads, animation follows.** Timing is driven by the recorded voiceover.
6. **Accessible.** Captions on every video, high contrast, no meaning carried by colour alone.
